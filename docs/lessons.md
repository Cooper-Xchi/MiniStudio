- 下一课：第 58 课（B05），非均匀缩放后的法线。
- 当前共 405 个课位：A 阶段 52 课，B 阶段 33 课（含按实际需要新增的 B02A），C～L 各 32 课；后续 350 个课位都是计划，未表示已经实现。
- B～L 保留原教案编号，实际开课时再登记连续课号；不预先创建分支或锁死远期顺序。

- 每次只推进一个 20～90 分钟核心任务。复盘、报告和图示默认在当课对话中完成，必要结论简记在对应行或 README，不另建交接与复盘文件。
- 详细历史和旧验证记录保留在 Git 历史中；当前构建、操作与平台验证状态见 [README](../README.md)。
