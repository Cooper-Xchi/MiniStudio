# I 阶段：2D 动画与视频素材引擎

[返回逐课索引](README.md) · 第 25～27 月／第 105～117 周

## 阶段前置与共同边界

H 阶段 v1.0 已验收，或已有真实工作任务可替代相应课位。Lottie 与 Spine 二选一，依目标素材、运行时能力、许可证和平台支持决定，不并行自研两套解析器。

动画资产、播放实例、解码任务、音视频时钟与 GPU 动态纹理分别拥有明确状态。视频先限定一种受控容器／编码／像素输出路径；解码库和音频设施先评估确认。2D 渲染能力只按当前格式需要扩展已有边界，不承诺一次支持所有特性或所有后端。

课内按顺序推进，后课以前课的验收成果为前置；每课只完成下列一个核心练习。若环境准备或实现超过 90 分钟，拆课并更新实际课号，不省略验收。所有实现课都须实际读改动并完成与风险相称的构建／运行检查；复盘课如改代码，也须补做行为回归。

## 第一组：一种 2D 动画格式

### I01：格式与运行时选型

- **用时**：35～60 分钟。
- **讲解**：Lottie／Spine 的表达方式、目标素材、运行时与许可差异。
- **核心练习与边界**：用一份目标素材比较两条路径，选一种并写支持范围后等确认。
- **验收**：选择有实际需求依据，版本／许可证／平台成本明确，不启动两套实现。

### I02：读取动画资源信息

- **用时**：50～80 分钟。
- **讲解**：动画时长、层／骨架数据、图片依赖与解析对象寿命。
- **核心练习与边界**：使用已确认运行时读取一份小素材，先输出元信息与依赖。
- **验收**：信息与样本一致，缺依赖和损坏数据可定位；项目不自写完整格式解析器。

### I03：固定时间的 2D 画面

- **用时**：60～90 分钟。
- **讲解**：运行时求值、绘制数据与渲染适配的边界。
- **核心练习与边界**：在一个固定时间显示小动画的一帧，限定受支持图元和效果。
- **验收**：画面可复现，超出支持范围有说明，运行时对象不泄漏到所有业务模块。

### I04：2D 运行时架构复盘

- **用时**：30～50 分钟。
- **讲解**：素材数据、运行时实例、绘制适配与纹理依赖的所有权。
- **核心练习与边界**：画固定帧求值路径，检查第三方类型和 GPU 生命周期。
- **验收**：更换播放器实例不必重复解析同一素材，底层不依赖编辑器 UI。

## 第二组：可控播放

### I05：播放、暂停与定位

- **用时**：45～75 分钟。
- **讲解**：播放时间、速率、暂停与时间跳转的语义。
- **核心练习与边界**：给 I03 加显式播放状态，用固定时间输入验证后再接真实时钟。
- **验收**：暂停画面稳定，定位同一时刻结果可重现，跳转不积累旧增量。

### I06：循环与边界事件

- **用时**：45～75 分钟。
- **讲解**：片段区间、末帧、循环次数与事件重复。
- **核心练习与边界**：对一段动画实现有限／无限循环策略，测试跨越末尾的大时间步。
- **验收**：不漏掉或无限重复结束事件，零时长素材有明确处理。

### I07：两段动画过渡

- **用时**：55～85 分钟。
- **讲解**：骨架姿态混合与画面交叉淡化的不同能力。
- **核心练习与边界**：按所选运行时支持做一种两段过渡；Lottie 路径可限定为画面淡化。
- **验收**：过渡起止连续，明确实现的是哪种混合，不把淡化宣称为骨架混合。

### I08：动画播放状态复盘

- **用时**：30～50 分钟。
- **讲解**：素材只读共享、实例时间、混合权重与资源寿命。
- **核心练习与边界**：用两实例不同时间播放检查状态隔离，记录运行时限制。
- **验收**：一个实例暂停不影响另一个，结束／取消能释放实例资源。

## 第三组：缓存与绘制成本

### I09：解析数据缓存

- **用时**：50～80 分钟。
- **讲解**：资源身份、内容版本、只读数据与实例状态分离。
- **核心练习与边界**：缓存所选格式的解析结果，创建两个独立播放器。
- **验收**：计数证明复用解析数据，两个播放时间独立，重载时版本语义明确。

### I10：图片依赖与图集边界

- **用时**：50～80 分钟。
- **讲解**：子图 UV、边缘采样、图集引用与资源复用。
- **核心练习与边界**：复用素材已有图集或整理一个小型图集样本，校验边缘显示。
- **验收**：小图位置正确，无明显串色；不自研通用打包优化器。

### I11：2D 绘制计数与合批实验

- **用时**：50～80 分钟。
- **讲解**：绘制顺序、混合／裁剪状态、可合并条件。
- **核心练习与边界**：测量小动画的提交，再只对一组兼容图元合批。
- **验收**：画面顺序不变，记录提交和耗时；无收益时保留原路径。

### I12：2D 资源与性能复盘

- **用时**：30～50 分钟。
- **讲解**：解析缓存、图集、动态数据和绘制顺序的代价。
- **核心练习与边界**：整理一页内存／提交账本，检查实例退出与资源保留。
- **验收**：能区分合理常驻缓存与泄漏，下一步视频不会复用不合适的动画状态类。

## 第四组：视频解码起步

### I13：视频范围与解码依赖评估

- **用时**：35～60 分钟。
- **讲解**：容器、编码、解复用、解码、音频输出与平台限制。
- **核心练习与边界**：选一份许可明确短片和一条解码路径，评估库／系统 API 后等确认。
- **验收**：容器、编码、像素输出、音频范围清楚，不承诺完整播放器兼容性。

### I14：流信息与时间基

- **用时**：45～75 分钟。
- **讲解**：stream、packet、frame、时间基与显示时间戳。
- **核心练习与边界**：在已确认依赖下读取短片元信息和前几个 packet 的时间信息。
- **验收**：能换算时间单位，坏文件可诊断，读取对象按 RAII 释放。

### I15：解码一帧到 CPU

- **用时**：60～90 分钟。
- **讲解**：packet 送入、frame 取出、缓冲复用与像素所有权。
- **核心练习与边界**：解码并保存一帧诊断数据，先不连续播放、不接 GPU。
- **验收**：帧尺寸／步长／格式明确，下一次解码不会破坏被保留帧的数据。

### I16：解码边界架构复盘

- **用时**：30～50 分钟。
- **讲解**：文件、解复用器、解码器、借用帧与项目自有帧的寿命。
- **核心练习与边界**：画一个 packet 到 CPU 图像的所有权路径，检查错误与退出。
- **验收**：渲染模块不调用解码 API，线程职责在接入后台前已明确。

## 第五组：视频时间与显示

### I17：按显示时间戳选帧

- **用时**：50～80 分钟。
- **讲解**：PTS、时间基、显示顺序与解码顺序可能不同。
- **核心练习与边界**：用受控帧序列实现按播放时钟选择当前帧，先用 CPU 数据。
- **验收**：可变间隔帧不按固定帧号硬播，晚帧策略明确。

### I18：动态纹理显示视频帧

- **用时**：60～90 分钟。
- **讲解**：重用纹理存储、像素步长、上传线程与帧寿命。
- **核心练习与边界**：把已选帧上传到一个固定尺寸动态纹理，先限定转换后的 RGBA。
- **验收**：短片连续可见，未每帧重建全部资源，解码与 GPU 使用无悬空共享。

### I19：视频颜色与方向校准

- **用时**：50～80 分钟。
- **讲解**：像素格式、颜色矩阵／范围、方向元数据与显示转换。
- **核心练习与边界**：用受控色条和方向样本核对 I18 的转换链路，只修正一条选定输出路径。
- **验收**：颜色和方向与参考一致，记录不支持的 HDR／其他颜色路径。

### I20：媒体时钟与纹理架构复盘

- **用时**：30～50 分钟。
- **讲解**：播放时钟、待显示帧、上传与呈现的边界。
- **核心练习与边界**：追踪一次帧从解码到显示的状态，并测量当前延迟来源。
- **验收**：时间戳不会被上传完成时间替代，GPU 资源仍由渲染线程拥有。

## 第六组：音画与定位

### I21：音频输出最小链路

- **用时**：60～90 分钟。
- **讲解**：采样率、通道、PCM 缓冲、输出回调与实时约束。
- **核心练习与边界**：使用已确认音频设施播放短片的受控 PCM 路径，先独立验证。
- **验收**：速度／音高正常，回调不做磁盘读取或长时间锁等待，退出可收尾。

### I22：以音频播放进度同步视频

- **用时**：60～90 分钟。
- **讲解**：主时钟、已消费采样、漂移、等帧／丢帧策略。
- **核心练习与边界**：用实际音频播放进度驱动 I17 选帧，先限定正常倍速。
- **验收**：记录音画偏差，长一点的片段不持续累积漂移；设备延迟局限注明。

### I23：跳转、清队列与恢复

- **用时**：60～90 分钟。
- **讲解**：seek、关键帧、解码器刷新与旧代次帧失效。
- **核心练习与边界**：支持一次用户定位到目标时间，丢弃旧音视频结果后恢复。
- **验收**：不闪回旧帧或播放旧音频，实际定位精度有记录。

### I24：音视频同步架构复盘

- **用时**：35～60 分钟。
- **讲解**：两种生产／消费节奏、时钟来源与取消代次。
- **核心练习与边界**：为暂停／定位／结束写状态表，检查锁与回调内工作。
- **验收**：所有终态可退出，UI 时间显示与真正播放时钟关系明确。

## 第七组：动态资源与生命周期

### I25：有界帧队列

- **用时**：50～80 分钟。
- **讲解**：解码领先、反压、丢帧与峰值内存。
- **核心练习与边界**：给现有解码完成队列设置预算，区分实时预览与保帧需求。
- **验收**：慢渲染下内存有界，音频／视频策略明确，不无条件积压全部帧。

### I26：纹理上传缓冲复用实验

- **用时**：60～90 分钟。
- **讲解**：在途 GPU 读取、缓冲环、完成条件与延迟。
- **核心练习与边界**：依据测量只对现有上传路径做一次有界复用实验。
- **验收**：峰值和帧时间有对照，GPU 使用结束前不覆写；无收益则保留简单路径。

### I27：媒体前后台与关闭

- **用时**：50～80 分钟。
- **讲解**：解码、音频输出、时钟与 Context 重建的协调。
- **核心练习与边界**：在一条实测平台路径验证后台暂停、回来恢复和播放中关闭。
- **验收**：无残留音频、旧帧发布或死锁，恢复位置符合约定。

### I28：动态媒体生命周期复盘

- **用时**：30～50 分钟。
- **讲解**：静态资产、播放器实例、CPU 帧与 GPU 帧的寿命。
- **核心练习与边界**：用账本检查峰值、结束后的资源保留和跨线程依赖。
- **验收**：能指出每份帧数据何时可回收，不用全局共享对象掩盖所有权。

## 第八组：统一预览与阶段成果

### I29：媒体描述扩展

- **用时**：45～75 分钟。
- **讲解**：时长、播放能力、类型专属参数与版本兼容。
- **核心练习与边界**：将选定 2D 格式和视频接入已有素材描述，保留能力差异。
- **验收**：老图片／3D 描述仍可读，静态资源不被迫拥有无用播放状态。

### I30：混合素材场景

- **用时**：50～80 分钟。
- **讲解**：各播放器时钟、组合顺序、透明与资源预算。
- **核心练习与边界**：用现有能力组合图片、2D 动画、视频和一个 3D 模型，不加新效果。
- **验收**：各自暂停／删除互不破坏，共用时间轴与独立播放的选择有说明。

### I31：媒体故障与性能报告

- **用时**：45～75 分钟。
- **讲解**：格式支持、同步误差、峰值与失败恢复证据。
- **核心练习与边界**：记录一个成功预览和一个损坏／取消案例，整理已有性能样本。
- **验收**：报告限定在所选格式和设备，包含已知音画／颜色兼容局限。

### I32：媒体阶段验收与季度复盘

- **用时**：50～80 分钟。
- **讲解**：多媒体能力、真实需求、维护成本与下一后端范围。
- **核心练习与边界**：审核现有演示、时钟／所有权图和回归结果，选择 Metal 最小场景。
- **验收**：已选 2D 格式与视频路径各可复现，未覆盖能力不作为完成项。
