# L 阶段：创作工作流与专家作品集

[返回逐课索引](README.md) · 第 34～36 月／第 144～156 周

> 状态：全部为待执行教案，开课时依据实际进度和工具支持复核。

## 阶段前置与共同边界

已有真实服务到客户端预览闭环、资源版本、可撤销操作、故障追踪与一次架构迁移证据。以一个实际创作流程为主线，优先映射工作或开源协作需求；没有真实需求时明确这是受控项目演练。

工作流负责步骤和恢复，工具负责明确的客户端操作，渲染与资源系统维持原边界。先复用稳定协议，是否引入编排框架或外部观测服务由真实缺口决定。外部调用、费用、作品公开和协作沟通按具体授权处理；课程本身不等于商业年限或专家资格。

课内按顺序推进，后课以前课的验收成果为前置；每课只完成下列一个核心练习。若环境准备或实现超过 90 分钟，拆课并更新实际课号，不省略验收。所有实现课都须实际读改动并完成与风险相称的构建／运行检查；复盘课如改代码，也须补做行为回归。

## 第一组：一个明确的多步骤流程

### L01：创作流程与完成定义

- **用时**：35～60 分钟。
- **讲解**：用户目标、输入、可查看产物、失败状态与操作范围。
- **核心练习与边界**：选择一个生成素材→导入→调整→预览的实际场景，写完成与失败样例。
- **验收**：每一步有可检查输出，不把“Agent 自己想办法”当需求。

### L02：步骤输入输出契约

- **用时**：45～75 分钟。
- **讲解**：类型、版本、资源引用、前置条件与结果校验。
- **核心练习与边界**：为 L01 各步骤定义小契约，复用现有工具而非重新实现客户端功能。
- **验收**：上一步输出能被下一步明确消费，坏结果在边界被拒绝。

### L03：可重放工作流状态机

- **用时**：50～80 分钟。
- **讲解**：步骤状态、依赖、运行 ID、终态与确定性事件。
- **核心练习与边界**：用假工具运行固定流程，保存事件序列并重放。
- **验收**：同序列得到同状态，步骤失败不误触发后续应用动作。

### L04：工作流职责复盘

- **用时**：30～50 分钟。
- **讲解**：规划、调度、工具执行、客户端事务和界面展示。
- **核心练习与边界**：画完整调用链，检查业务规则是否被重复写在 Prompt 和代码中。
- **验收**：关键约束由客户端校验，模型文本不能绕过资源／操作边界。

## 第二组：操作范围与失败恢复

### L05：操作范围与人工审阅点

- **用时**：45～75 分钟。
- **讲解**：可逆修改、外部副作用、最小权限与具体变化预览。
- **核心练习与边界**：为流程标记需要审阅的实际操作，并先产出可查看的差异。
- **验收**：用户看到的是明确改动或产物，普通可逆步骤不被无意义确认打断。

### L06：步骤超时与取消传播

- **用时**：50～80 分钟。
- **讲解**：单步截止、整体期限、取消树与晚到结果。
- **核心练习与边界**：用假工具卡住一个步骤，传递取消并终止后续调度。
- **验收**：流程进入明确终态，后台结果不会偷偷应用到场景。

### L07：一个补偿操作

- **用时**：50～80 分钟。
- **讲解**：撤销、补偿、不可逆副作用与补偿自身失败。
- **核心练习与边界**：为已创建临时场景实例定义补偿，并模拟预览步骤失败。
- **验收**：可撤销部分恢复，无法补偿的产物如实记录，不伪装成全事务回滚。

### L08：恢复语义架构复盘

- **用时**：30～50 分钟。
- **讲解**：调度失败、工具失败、客户端状态与外部状态。
- **核心练习与边界**：为一次部分成功画状态表，检查错误归因与恢复责任。
- **验收**：能说明哪些状态可重试、可撤销或需用户处理，没有无限自动重试。

## 第三组：可靠执行与恢复运行

### L09：工具调用幂等

- **用时**：50～80 分钟。
- **讲解**：逻辑操作 ID、重复消息、结果存储与重试契约。
- **核心练习与边界**：对一个会创建资源的工具模拟响应丢失，复用同一操作 ID。
- **验收**：重试不创建重复实例，过期 ID 和内容变化的处理有明确规则。

### L10：工作流检查点

- **用时**：50～80 分钟。
- **讲解**：持久化状态、产物引用、版本和未完成副作用。
- **核心练习与边界**：在步骤边界保存最小检查点，不序列化线程或 GPU 句柄。
- **验收**：重读能判断已完成步骤，坏检查点被拒绝，凭据不进入状态文件。

### L11：中断后恢复运行

- **用时**：60～90 分钟。
- **讲解**：恢复前核对外部状态、失效资源、重放与继续。
- **核心练习与边界**：受控中断一次假服务流程，再从 L10 检查点恢复。
- **验收**：不重复已完成副作用，失效产物触发明确重新验证或失败。

### L12：持久化与幂等复盘

- **用时**：35～60 分钟。
- **讲解**：本地记录和外部结果间的不确定窗口、状态对账。
- **核心练习与边界**：列出保存前后中断的两种时序并验证恢复策略。
- **验收**：不宣称无法保证的 exactly-once，能解释重复风险如何受控。

## 第四组：增量素材安全应用

### L13：素材候选版本

- **用时**：45～75 分钟。
- **讲解**：稳定身份、内容版本、依赖版本与当前使用版本。
- **核心练习与边界**：让新生成产物作为候选版本进入缓存，不立即替换当前场景。
- **验收**：旧版本仍可用，候选来源和校验状态可追踪。

### L14：变化比较与预览

- **用时**：50～80 分钟。
- **讲解**：参数差异、依赖变化、视觉预览与语义比较。
- **核心练习与边界**：对一个候选材质或图片生成可审阅差异及固定相机预览。
- **验收**：能看出具体变化，预览使用候选资源但不污染正式场景。

### L15：帧边界应用与撤回

- **用时**：50～80 分钟。
- **讲解**：候选提交、原版本保留、依赖一致性与撤销命令。
- **核心练习与边界**：将已通过校验的候选应用为一个可撤销场景操作。
- **验收**：可见结果与预览约定一致，撤回恢复旧版本，失败不提交半份依赖。

### L16：增量应用架构复盘

- **用时**：30～50 分钟。
- **讲解**：生成任务、候选缓存、预览场景与正式场景的隔离。
- **核心练习与边界**：追踪候选从生成到释放的所有权和预算，检查旧版本保留规则。
- **验收**：没有无界版本堆积，生成服务不能直接修改活跃 GPU 资源。

## 第五组：不同素材的更新切片

### L17：图片生成结果更新

- **用时**：50～80 分钟。
- **讲解**：尺寸、颜色语义、材质引用与图片替换边界。
- **核心练习与边界**：复用既有真实服务或记录产物，完成一次候选图片的校验／预览／应用。
- **验收**：替换后方向和材质语义正确，旧结果晚到不会覆盖新选择。

### L18：动画参数增量更新

- **用时**：50～80 分钟。
- **讲解**：动画素材与播放实例、片段／速率参数、时间连续性。
- **核心练习与边界**：对已有受支持动画做一个明确参数更新，不要求生成新动画格式。
- **验收**：修改可预览撤销，播放状态不意外重置；真实生成能力另按服务支持验证。

### L19：3D 素材候选替换

- **用时**：60～90 分钟。
- **讲解**：网格／材质依赖、包围体、场景引用与兼容限制。
- **核心练习与边界**：对同一实例切换一份受控模型候选，复用现有导入与版本流程。
- **验收**：依赖完整才提交，坏模型保留旧实例，骨架不兼容时明确拒绝。

### L20：跨素材更新契约复盘

- **用时**：35～60 分钟。
- **讲解**：公共提交协议和类型专属校验的分界。
- **核心练习与边界**：比较图片、动画参数和模型三条路径，整理共同步骤与差异。
- **验收**：不把三类素材硬塞进无类型 payload，未接入的生成能力不标已实现。

## 第六组：编排与可观测性

### L21：编排框架必要性评估

- **用时**：35～60 分钟。
- **讲解**：自有状态机、现成框架的能力、调试成本和依赖锁定。
- **核心练习与边界**：根据现有缺口评估至多一种编排框架，形成采用或不采用的理由。
- **验收**：没有缺口就保留现状；若需要新增依赖，说明成本并等待确认。

### L22：编排适配或现有调度补齐

- **用时**：60～90 分钟。
- **讲解**：协议隔离、事件映射和框架外可测试的业务契约。
- **核心练习与边界**：若已批准框架，仅迁移一个步骤；否则完善一个已有调度缺口。
- **验收**：同一假工具序列结果一致，核心客户端工具不依赖框架内部类型。

### L23：端到端观测视图

- **用时**：50～80 分钟。
- **讲解**：trace／步骤事件、延迟、错误、费用记录与敏感数据。
- **核心练习与边界**：用现有日志或已确认的一种工具显示一次完整工作流时间线。
- **验收**：能定位慢步骤与失败阶段，费用只记实际可得数据，凭据与私人素材不泄露。

### L24：编排与观测架构复盘

- **用时**：30～50 分钟。
- **讲解**：业务状态、框架适配、诊断与外部服务依赖。
- **核心练习与边界**：演练观测不可用或适配器失败，检查业务是否仍有明确结果。
- **验收**：观测失败不误报业务成功，框架替换边界清楚，依赖有维护理由。

## 第七组：端到端质量

### L25：创作延迟与资源基线

- **用时**：45～75 分钟。
- **讲解**：服务等待、下载／校验、导入、上传和预览时间。
- **核心练习与边界**：对固定流程采样并分段统计，标明网络与服务波动。
- **验收**：数值能关联同一运行，未把服务端耗时归因成客户端渲染问题。

### L26：失败恢复矩阵

- **用时**：50～80 分钟。
- **讲解**：网络超时、坏素材、失效目标、重启与部分成功。
- **核心练习与边界**：用已存在的注入点执行一份有限矩阵，保留最小失败序列。
- **验收**：每格有预期和实测，错误能恢复或明确停下，不以日志无报错代替验证。

### L27：平台与后端兼容回归

- **用时**：50～80 分钟。
- **讲解**：同一素材／工具契约、能力差异、结果容差与覆盖范围。
- **核心练习与边界**：在实际可用的两条路径复演核心创作流程，整理支持矩阵。
- **验收**：平台结果各自记录，未测／不支持与失败明确区分。

### L28：系统质量架构复盘

- **用时**：35～60 分钟。
- **讲解**：性能、恢复、权限边界、诊断与维护成本的全链路取舍。
- **核心练习与边界**：回顾矩阵和时间线，选择一个真正需要收敛的复杂点。
- **验收**：结论对应证据，未完成问题形成补课而非带病宣称专家级成果。

## 第八组：真实协作与表达

### L29：系统设计讲解演练

- **用时**：45～75 分钟。
- **讲解**：从需求、约束到边界、生命周期、瓶颈和回退的表达。
- **核心练习与边界**：用自己的架构完成一次限时讲解，再根据追问修订一页图。
- **验收**：每个模块能对应实际代码与证据，能说明没有采用的方案及原因。

### L30：渲染与故障案例集

- **用时**：45～75 分钟。
- **讲解**：症状、假设、工具、定位、修复和回归的完整案例。
- **核心练习与边界**：从已有记录选三类不同问题，整理可检查的案例入口。
- **验收**：案例来自真实实验或项目，区分受控故障与生产事故，不虚构经历。

### L31：真实协作贡献准备

- **用时**：50～80 分钟。
- **讲解**：问题范围、设计讨论、可审阅改动、验证与协作反馈。
- **核心练习与边界**：基于真实工作／开源机会准备一份有明确边界的贡献材料；对外操作按授权。
- **验收**：材料有实际问题和证据；未参与协作时明确是准备稿，不把模拟计为履历。

### L32：三年复盘与后续方向

- **用时**：60～90 分钟。
- **讲解**：模块责任、架构影响、维护结果、实际年限与岗位差距。
- **核心练习与边界**：审阅作品集、协作材料和未完成项，依据当时真实机会制定下一阶段。
- **验收**：能展示功能、测量、迁移和恢复证据；课程完成不自动等同高级／专家任职资格。
