## 阶段前置与共同边界

C 阶段同步资源边界、句柄失效和候选提交已经验收。并发部分先在小型 CPU 实验中验证，再接回现有渲染循环。

后台线程只做 I/O、解码和解析；拥有 current context 的主线程执行 GPU 创建、上传和释放。任务拥有输入与输出，禁止把短命引用捕获到后台。先用 mutex／condition_variable，原子变量只做小实验。ImGui 等依赖先评估确认，动画先支持一份明确受控的 glTF 样本。

课内按顺序推进，后课以前课的验收成果为前置；每课只完成下列一个核心练习。若环境准备或实现超过 90 分钟，拆课并更新实际课号，不省略验收。所有实现课都须实际读改动并完成与风险相称的构建／运行检查；复盘课如改代码，也须补做行为回归。

## 第一组：线程与正确同步

### D01：jthread 与线程寿命

- **用时**：40～70 分钟。
- **讲解**：线程入口、值捕获／引用捕获、join 与作用域。
- **核心练习与边界**：用一个 CPU 工作任务验证创建和结束；明确工作对象由谁拥有。
- **验收**：主线程退出前工作已收尾，能解释捕获栈引用的悬空风险。

### D02：互斥保护共享状态

- **用时**：45～75 分钟。
- **讲解**：数据竞争、临界区、lock_guard 与锁的粒度。
- **核心练习与边界**：在小计数实验中重现无同步问题，再用 mutex 保护共享数据。
- **验收**：结果稳定，能说明只保护写入为什么不足；不靠 sleep 充当同步。

### D03：条件变量阻塞队列

- **用时**：60～90 分钟。
- **讲解**：谓词等待、虚假唤醒、队列状态与关闭标志。
- **核心练习与边界**：写一个单生产者／单消费者任务队列，支持有序关闭。
- **验收**：空队列不忙等，关闭可唤醒等待者，锁内不执行耗时任务。

### D04：并发所有权复盘

- **用时**：30～50 分钟。
- **讲解**：谁可读写、由哪把锁保护、线程退出依赖。
- **核心练习与边界**：为队列与任务画共享数据表和时序图，检查捕获和析构。
- **验收**：每项共享状态有同步规则，不引入无锁队列或可变全局状态。

## 第二组：后台工作到主线程上传

### D05：后台读取文件

- **用时**：50～80 分钟。
- **讲解**：任务输入复制、文件 I/O 与渲染帧的解耦。
- **核心练习与边界**：将一份资源的文件读取放入已有队列，结果先返回 CPU 字节。
- **验收**：渲染可继续，缺文件错误随任务返回，工作线程没有 OpenGL 调用。

### D06：后台解码与完成队列

- **用时**：55～85 分钟。
- **讲解**：CPU 结果所有权、移动大缓冲、完成通知。
- **核心练习与边界**：在工作线程解码图片并把拥有像素的结果移交主线程。
- **验收**：像素仅有明确所有者，取消／失败结果不会留下悬空 data() 指针。

### D07：每帧上传预算

- **用时**：50～80 分钟。
- **讲解**：完成结果消费、GPU 线程约束、时间／数量预算。
- **核心练习与边界**：主线程逐帧消费完成队列，先以固定数量控制上传。
- **验收**：多图加载仍响应输入，记录帧时间；单次大上传的剩余局限明确。

### D08：异步加载链路复盘

- **用时**：30～50 分钟。
- **讲解**：请求、工作、完成、上传、发布的状态与责任。
- **核心练习与边界**：用一张时序图追踪一次加载成功和失败，检查跨线程容器访问。
- **验收**：后台不访问 Scene 活跃对象或 GPU 句柄，结果发布点明确。

## 第三组：取消、异常与退出

### D09：任务取消与过期结果

- **用时**：50～80 分钟。
- **讲解**：协作式取消、请求版本、取消不等于强杀线程。
- **核心练习与边界**：场景切换时标记旧任务，工作检查取消并丢弃过期完成结果。
- **验收**：晚到结果不会覆盖新场景；无法中断的库调用有明确局限。

### D10：停止与安全关闭

- **用时**：55～85 分钟。
- **讲解**：停止接收、通知等待者、排空／放弃策略与 join 顺序。
- **核心练习与边界**：处理加载中关闭程序，按约定收尾 CPU 任务后释放 GPU 与窗口。
- **验收**：多个关闭时机均可退出，无死锁、后台访问已销毁对象或残留任务。

### D11：future 与异常传播

- **用时**：45～75 分钟。
- **讲解**：promise／future、单次取值、异常与结果返回。
- **核心练习与边界**：用一个独立小任务比较显式结果和 future 传播错误；不强换全队列。
- **验收**：异常不逃逸导致线程终止，能说明在哪个线程观察失败。

### D12：取消与退出故障复盘

- **用时**：30～50 分钟。
- **讲解**：生命周期竞态、卡住的等待、锁顺序与错误归因。
- **核心练习与边界**：对两种故障写最小重现与时序，验证已有关闭契约。
- **验收**：每条失败路径有终态，记录适用的线程诊断工具与未覆盖情况。

## 第四组：原子与任务可观测性

### D13：顺序一致原子小实验

- **用时**：40～65 分钟。
- **讲解**：原子性、内存可见性与复合不变量的区别。
- **核心练习与边界**：用默认顺序一致原子做一个独立计数实验，比较互斥方案。
- **验收**：能解释 atomic 计数不使旁边的 vector 自动线程安全；不改生产队列。

### D14：发布与获取的最小实验

- **用时**：45～75 分钟。
- **讲解**：happens-before、release／acquire 配对和数据发布。
- **核心练习与边界**：在不超过约 30 行的单次发布实验中说明数据可见性，保留明确生命周期。
- **验收**：能逐步说明同步链；不能解释则回到 mutex，不进入弱内存序优化。

### D15：任务状态与进度快照

- **用时**：45～75 分钟。
- **讲解**：稳定任务 ID、不可变快照、进度与终态。
- **核心练习与边界**：主线程获取最小任务状态快照并打印；不引入完整任务管理框架。
- **验收**：成功、失败、取消可区分，后台与界面不直接共享可变容器。

### D16：并发阶段验收与 v0.6 复盘

- **用时**：40～70 分钟。
- **讲解**：响应性、正确性、关闭证据与性能取舍。
- **核心练习与边界**：回归已有加载／取消／退出场景，整理 v0.6 的时序和资源说明。
- **验收**：任务寿命与线程约束可解释，未证明的原子优化不进入主线。

## 第五组：最小编辑界面

### D17：ImGui 接入方案与依赖评估

- **用时**：30～60 分钟。
- **讲解**：即时模式界面、平台／渲染适配、版本与许可证。
- **核心练习与边界**：评估现有 GLFW／OpenGL 适配的接入位置，写帧顺序草图后等确认。
- **验收**：能说明依赖用途与替代方案，GUI 不反向拥有整个 Application。

### D18：第一个编辑面板

- **用时**：60～90 分钟。
- **讲解**：GUI 初始化／帧开始／提交／销毁与输入捕获。
- **核心练习与边界**：在已确认依赖下显示一个只读性能小面板，保持场景操作。
- **验收**：面板可见且退出无资源错误，鼠标被 UI 占用时不会误转相机。

### D19：材质参数编辑

- **用时**：45～75 分钟。
- **讲解**：UI 临时值、校验、应用命令与数据所有权。
- **核心练习与边界**：让一个控件编辑选定材质的粗糙度，并经过已有参数校验。
- **验收**：合法修改立即显示，范围错误被处理，UI 不直接操作 OpenGL。

### D20：编辑器边界复盘

- **用时**：30～50 分钟。
- **讲解**：展示层、场景操作、资源服务与渲染流程的依赖。
- **核心练习与边界**：画出一次滑块变化的数据路径，检查输入捕获和销毁顺序。
- **验收**：GUI 可被关闭而核心场景仍运行，不形成万能 Editor Manager。

## 第六组：场景检查与动态实例

### D21：节点检查面板

- **用时**：50～80 分钟。
- **讲解**：稳定选中 ID、节点删除后的选择失效与属性展示。
- **核心练习与边界**：显示场景树及选中节点 TRS／资源引用信息；先只读。
- **验收**：删除被选中节点不会访问悬空对象，资源缺失可定位到节点。

### D22：最小 Sprite 绘制

- **用时**：50～80 分钟。
- **讲解**：2D 坐标、正交投影、共享几何与实例参数。
- **核心练习与边界**：在独立小场景绘制两个使用已有纹理的 Sprite。
- **验收**：屏幕位置与尺寸可预测，透明状态不污染原 3D 场景。

### D23：有界粒子更新

- **用时**：60～90 分钟。
- **讲解**：生命周期、固定容量容器、更新／回收与确定性随机。
- **核心练习与边界**：用固定数量上限做一种 CPU 粒子效果，复用 Sprite 绘制。
- **验收**：到期粒子被回收，数量有上限，相同种子便于重现；不做 GPU 粒子。

### D24：动态对象与编辑边界复盘

- **用时**：30～50 分钟。
- **讲解**：场景状态、临时粒子、共享素材和 UI 选择的寿命。
- **核心练习与边界**：记录容器扩容／删除与引用失效，检查每帧是否重复创建 GPU 资源。
- **验收**：动态效果有容量界限，稳定纹理与网格不每帧重建。

## 第七组：动画时间与骨架

### D25：关键帧时间与插值

- **用时**：50～80 分钟。
- **讲解**：时间采样、区间查找、边界、循环与线性插值。
- **核心练习与边界**：从受控 glTF 动画读取一个平移通道，驱动已有节点。
- **验收**：关键时刻与中点位置可预测，末帧和循环边界有测试。

### D26：旋转关键帧与四元数

- **用时**：50～80 分钟。
- **讲解**：四元数表示旋转、归一化和球面插值的目的。
- **核心练习与边界**：用同一时间采样接口加入一个旋转通道；暂不做动画混合。
- **验收**：插值连续、旋转长度正常，能解释不能直接插值角度跨界的原因。

### D27：骨架层级姿态

- **用时**：55～85 分钟。
- **讲解**：关节索引、局部姿态、层级组合与骨架可视化。
- **核心练习与边界**：在 CPU 更新一份小骨架，先用线段显示关节关系。
- **验收**：根与子关节运动正确，坏关节引用被拒绝；暂不蒙皮网格。

### D28：动画数据与时间架构复盘

- **用时**：30～50 分钟。
- **讲解**：动画素材、播放状态、采样结果和场景变换的区别。
- **核心练习与边界**：画一份素材被两个播放器使用的所有权图。
- **验收**：两个播放时间可独立，素材保持只读，骨架更新不反向依赖 UI。

## 第八组：蒙皮与首年成果

### D29：绑定姿态与 CPU 蒙皮验证

- **用时**：60～90 分钟。
- **讲解**：inverse bind、权重、关节矩阵及坐标空间。
- **核心练习与边界**：用少量顶点做 CPU 蒙皮数值实验，检查权重和关节索引。
- **验收**：绑定姿态还原原网格，单关节变换符合手算；不先调复杂 Shader。

### D30：最小 GPU 蒙皮

- **用时**：60～90 分钟。
- **讲解**：关节矩阵上传、顶点权重输入与平台容量限制。
- **核心练习与边界**：将 D29 已验证的小骨架迁入顶点 Shader，限定支持的关节数。
- **验收**：与 CPU 样本结果一致，超限模型明确拒绝，不出现越界访问。

### D31：动画播放控件与演示

- **用时**：45～75 分钟。
- **讲解**：播放、暂停、定位时间和循环的状态转换。
- **核心练习与边界**：给现有动画加最小播放控件，录制一段异步加载到动画预览的演示。
- **验收**：暂停不推进时间、定位可重现姿态，取消旧加载不替换当前动画。

### D32：v0.7 验收、架构与年度复盘

- **用时**：60～90 分钟。
- **讲解**：并发、界面、动画证据与真实岗位要求的差距。
- **核心练习与边界**：汇总已完成材料，做首版作品说明和一次基于当时真实 JD 的差距复盘。
- **验收**：成果与未支持范围清楚，实际运行平台各自有证据；确定 E 阶段测量重点。
