## 阶段前置与共同边界

B 阶段模型、材质与多遍渲染已经稳定。先使用三个节点和两份资源的固定小场景，不在这一阶段自研完整 ECS。

场景拥有节点和组件值；资源容器拥有实际 CPU／GPU 资源，节点使用可检查的引用或句柄。明确线程仍为主线程，先把同步加载、失败回滚与版本替换做好。JSON 等新依赖先评估确认；磁盘路径与第三方类型不应进入底层绘制命令。

课内按顺序推进，后课以前课的验收成果为前置；每课只完成下列一个核心练习。若环境准备或实现超过 90 分钟，拆课并更新实际课号，不省略验收。所有实现课都须实际读改动并完成与风险相称的构建／运行检查；复盘课如改代码，也须补做行为回归。

## 第一组：最小场景数据

### C01：节点标识与存储

- **用时**：45～75 分钟。
- **讲解**：稳定 ID、vector 扩容、地址失效与索引的区别。
- **核心练习与边界**：用三个节点建立最小 Scene 数据容器；暂时仅支持新增与查询。
- **验收**：新增节点后旧 ID 仍能查到对象，能够解释为何不能缓存 vector 元素地址。

### C02：Transform 值组件

- **用时**：45～70 分钟。
- **讲解**：位置、旋转、缩放值与派生矩阵，组合优于继承。
- **核心练习与边界**：把节点局部 TRS 整理成独立值数据，接回既有矩阵计算。
- **验收**：修改一个节点只改变对应物体，组件不拥有 GPU 句柄。

### C03：父子世界变换

- **用时**：50～80 分钟。
- **讲解**：层级遍历、父矩阵与局部矩阵的组合顺序。
- **核心练习与边界**：给三个节点建立单根层级，递归或迭代求世界矩阵。
- **验收**：父移动带动子、子移动不影响父；循环关系被拒绝。

### C04：场景职责与依赖复盘

- **用时**：25～45 分钟。
- **讲解**：Scene、Transform、绘制实例和 GPU 资源之间的边界。
- **核心练习与边界**：为三个节点画所有权图与一次更新顺序，不扩展完整组件框架。
- **验收**：Renderer 可消费普通绘制数据，底层资源不依赖 Scene。

## 第二组：层级编辑与失效

### C05：变换脏标记

- **用时**：45～75 分钟。
- **讲解**：派生数据、失效传播与重复计算的成本。
- **核心练习与边界**：对已有层级加入最小脏标记，并用计数比较更新节点数量。
- **验收**：父变更会更新后代、无变化时不重复计算，记录增加的状态成本。

### C06：重新挂接节点

- **用时**：50～80 分钟。
- **讲解**：保持局部或世界变换的两种语义、逆矩阵边界。
- **核心练习与边界**：只实现一种明确的重新挂接策略，拒绝形成环。
- **验收**：用前后世界位置验证语义，不能求逆的父变换有明确失败结果。

### C07：删除节点与引用失效

- **用时**：50～80 分钟。
- **讲解**：删除子树、悬空 ID、容器擦除与索引移动。
- **核心练习与边界**：实现一种明确的节点删除策略，同时修正父子关系。
- **验收**：删除后查询不会误指向其他节点，重复删除有可解释结果。

### C08：层级不变量复盘

- **用时**：30～50 分钟。
- **讲解**：唯一父节点、无环、有效引用与根节点规则。
- **核心练习与边界**：列出不变量并检查重挂接／删除的失败边界。
- **验收**：三个受控反例被识别；若拆分逻辑，原场景行为保持一致。

## 第三组：可保存的场景

### C09：场景格式与 JSON 依赖评估

- **用时**：30～60 分钟。
- **讲解**：持久化 ID、版本号、运行时句柄不可直接保存。
- **核心练习与边界**：为三节点场景写最小格式样例，评估解析依赖和许可后等确认。
- **验收**：样例含版本、父关系、TRS 与资源键，不含进程内指针或 GPU 句柄。

### C10：读取版本 1 场景

- **用时**：60～90 分钟。
- **讲解**：字段校验、枚举解析、必需／可选数据与错误位置。
- **核心练习与边界**：在已确认依赖下解析小场景到临时数据，校验通过才替换当前场景。
- **验收**：坏字段保留旧场景，错误能定位节点与字段，不显示半成品。

### C11：保存与往返验证

- **用时**：45～75 分钟。
- **讲解**：可重复输出、浮点容差、临时文件与替换时机。
- **核心练习与边界**：保存当前小场景再重新加载，比对关键语义；不做自动保存系统。
- **验收**：节点关系和 TRS 往返一致，写入失败不会先清空已有文件。

### C12：持久化边界复盘

- **用时**：30～50 分钟。
- **讲解**：文件模型与运行时模型的转换、版本迁移责任。
- **核心练习与边界**：记录格式约束与失败流程，并讨论未来加字段的兼容方法。
- **验收**：解析器不调用绘制命令，存储格式与内存布局没有隐式绑定。

## 第四组：资源复用与句柄

### C13：资源键与缓存身份

- **用时**：40～65 分钟。
- **讲解**：路径规范化、加载选项和同名资源的区别。
- **核心练习与边界**：为同图不同用途定义可比较资源键，验证键相等规则。
- **验收**：同源同选项复用、不同颜色语义可区分，不能只拿文件名当身份。

### C14：同步纹理缓存

- **用时**：55～85 分钟。
- **讲解**：unordered_map、查找／插入、唯一资源所有权。
- **核心练习与边界**：建立一个只管理纹理的同步容器，让两个节点复用同一资源。
- **验收**：计数证明只解码／上传一次，加载失败不留下假成功条目。

### C15：代际句柄与失效检测

- **用时**：55～85 分钟。
- **讲解**：槽位索引、generation、空句柄和陈旧引用。
- **核心练习与边界**：给纹理容器加最小可验证句柄，模拟释放后复用槽位。
- **验收**：旧句柄不会访问新资源，无效访问返回明确结果。

### C16：资源容器架构复盘

- **用时**：30～50 分钟。
- **讲解**：所有权、查找身份、生命周期身份与使用者依赖。
- **核心练习与边界**：画出节点到句柄再到纹理的路径，检查容器是否承担了解码以外的职责。
- **验收**：只有容器释放实际资源，Scene 与底层 OpenGL 无循环依赖。

## 第五组：共享边界与类型约束

### C17：网格资源复用

- **用时**：50～80 分钟。
- **讲解**：共享几何与每实例变换、批量容器中的独占资源。
- **核心练习与边界**：把两个重复导入的网格实例接到同一份 GPU 网格。
- **验收**：资源计数下降而两个实例位置独立；本课不实现实例化绘制。

### C18：类型化资源句柄

- **用时**：45～75 分钟。
- **讲解**：小模板、类型参数与编译期类型区分。
- **核心练习与边界**：在现有句柄上区分 Texture 与 Mesh 类型；不编写泛型资源框架。
- **验收**：错类型使用在编译阶段被拒绝，运行时失效检查仍保留。

### C19：占位资源与缺失提示

- **用时**：45～70 分钟。
- **讲解**：可恢复失败、默认材质与占位资源的生命周期。
- **核心练习与边界**：给缺失纹理接入已有占位图，并保留资源级错误信息。
- **验收**：场景仍可浏览，用户能找到失败资源；占位资源不会被单个节点提前释放。

### C20：共享所有权方案复盘

- **用时**：30～50 分钟。
- **讲解**：shared_ptr、weak_ptr 与显式容器／句柄各自的成本和边界。
- **核心练习与边界**：用当前场景比较两种方案，记录为什么保留或改变当前所有权。
- **验收**：能解释循环引用与引用计数不等于线程安全；不为练语法强换方案。

## 第六组：Shader 热重载

### C21：源码文件与修改检测

- **用时**：45～75 分钟。
- **讲解**：文件版本、修改时间局限、内容摘要与轮询。
- **核心练习与边界**：把一个 Shader 移到受控源码文件，检测变化并仅打印事件。
- **验收**：同内容不反复触发，文件短暂不可读有记录；不接平台 watcher 依赖。

### C22：候选 Shader 编译

- **用时**：50～80 分钟。
- **讲解**：候选对象、失败保留旧资源、错误日志归属。
- **核心练习与边界**：检测变化后编译候选 Program，先验证不替换的成功／失败路径。
- **验收**：错误 Shader 不影响当前画面，候选失败资源完整释放。

### C23：帧边界替换 Program

- **用时**：50～80 分钟。
- **讲解**：单线程提交点、uniform 状态重建与旧资源释放。
- **核心练习与边界**：在安全帧边界应用已成功的候选 Program，重新设置必要 uniform。
- **验收**：正确修改可见，坏修改保留旧效果；解释这里的替换不需要无锁原子结构。

### C24：热重载事务边界复盘

- **用时**：30～50 分钟。
- **讲解**：检测、构建、校验、提交、回滚五个阶段。
- **核心练习与边界**：画出 Shader 版本状态图，检查引用与当前 Program 的寿命。
- **验收**：不先删除旧 Program 再尝试编译，GPU 调用仍限主线程。

## 第七组：纹理与材质重载

### C25：纹理候选替换

- **用时**：55～85 分钟。
- **讲解**：新像素／新纹理所有权、尺寸变化与失败回滚。
- **核心练习与边界**：将已有 Shader 候选模式应用到一张纹理，不并发解码。
- **验收**：换尺寸图可见，坏图不让旧纹理消失，旧句柄使用语义有记录。

### C26：材质配置重载

- **用时**：45～75 分钟。
- **讲解**：参数范围校验、资源引用解析与整体提交。
- **核心练习与边界**：从小配置文件重载一个材质值对象，所有字段有效才提交。
- **验收**：非法粗糙度或坏资源引用给出明确结果，旧材质继续可用。

### C27：修改合并与重试节奏

- **用时**：45～70 分钟。
- **讲解**：连续保存事件、去抖、失败版本与重复工作。
- **核心练习与边界**：用可控时间输入合并同一资源的短时间修改；不新增后台线程。
- **验收**：连续保存只提交最终版本，不无限编译同一失败内容。

### C28：资源版本依赖复盘

- **用时**：30～50 分钟。
- **讲解**：稳定身份、内容版本及使用者更新方式。
- **核心练习与边界**：追踪同一纹理被两个材质引用时的替换过程，检查不变量。
- **验收**：两个使用者按既定语义一致更新，旧版本何时释放可说明。

## 第八组：卸载、回归与 v0.5

### C29：资源释放策略

- **用时**：45～75 分钟。
- **讲解**：显式卸载、活跃使用者、引用跟踪与常驻占位资源。
- **核心练习与边界**：实现一个场景卸载后的受控清理策略，先不用 LRU。
- **验收**：无使用者资源可释放，仍被其他场景使用的资源保留。

### C30：反复加载与退出检查

- **用时**：45～75 分钟。
- **讲解**：计数基线、泄漏与缓存保留的区别、Context 销毁顺序。
- **核心练习与边界**：重复加载／卸载同一小场景，记录资源计数并检查退出。
- **验收**：计数回到约定基线，适用的 Sanitizer 与 OpenGL 检查无未处理错误。

### C31：热重载故障演示

- **用时**：40～65 分钟。
- **讲解**：可重放操作、错误反馈与恢复证据的表达。
- **核心练习与边界**：整理一次正确修改、一次损坏修改、一次修复的演示及重现步骤。
- **验收**：演示证明旧版本可用，日志能关联文件和版本，不只录成功效果。

### C32：v0.5 验收与季度复盘

- **用时**：45～75 分钟。
- **讲解**：场景可保存、资源可复用、失败可恢复的整体契约。
- **核心练习与边界**：用已有证据验收并复盘所有权和投入，列出异步前必须补齐的边界。
- **验收**：加载／卸载／重载结果可复现；D 阶段不会在不清楚寿命的对象上直接加线程。
