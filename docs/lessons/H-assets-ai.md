# H 阶段：素材协议与 AI 工具链

[返回逐课索引](README.md) · 第 22～24 月／第 92～104 周

> 状态：全部为待执行教案，开课时依据实际进度和工具支持复核。

## 阶段前置与共同边界

场景、资源、异步任务与最小后端边界已经稳定。先使用可重放的本地假服务完成协议和失败路径，再选择一种真实服务；没有真实接入证据时不宣称 AI 闭环完成。

素材描述、网络任务、客户端操作与渲染资源分别负责各自生命周期。服务凭据放在适合运行环境的配置／凭据设施中，不能进入仓库、日志或演示包。HTTP、JSON Schema 校验与服务依赖按需评估并确认，框架和 RAG 不是必修实现。

课内按顺序推进，后课以前课的验收成果为前置；每课只完成下列一个核心练习。若环境准备或实现超过 90 分钟，拆课并更新实际课号，不省略验收。所有实现课都须实际读改动并完成与风险相称的构建／运行检查；复盘课如改代码，也须补做行为回归。

## 第一组：素材描述与导入

### H01：统一素材描述版本

- **用时**：40～70 分钟。
- **讲解**：素材 ID、类型、内容版本、来源和运行时产物的区别。
- **核心练习与边界**：为图片／3D／动画各写一份同结构描述样例，保留类型专属字段。
- **验收**：可定位原始文件与依赖，不把“统一”做成无法校验的万能字符串字典。

### H02：描述版本兼容

- **用时**：45～75 分钟。
- **讲解**：必需／可选字段、版本协商、旧数据迁移。
- **核心练习与边界**：给已有场景或素材描述增加一个字段，并写最小旧版转换。
- **验收**：旧样本可读，未知不兼容版本明确拒绝，转换不改写原始素材。

### H03：素材依赖图与导入结果

- **用时**：50～80 分钟。
- **讲解**：依赖闭包、循环检测、缓存键与部分失败。
- **核心练习与边界**：为一个模型生成纹理依赖清单，并以候选方式形成导入结果。
- **验收**：缺一张图时错误可定位，发布前不留下半导入场景。

### H04：素材模型架构复盘

- **用时**：30～50 分钟。
- **讲解**：源描述、转换产物、资源缓存和场景实例的边界。
- **核心练习与边界**：画一份素材从磁盘到预览的路径，检查版本与身份是否混用。
- **验收**：底层渲染器不依赖服务协议，格式升级不要求重写 GPU 资源类。

## 第二组：可撤销编辑与预览产物

### H05：一个参数修改的撤销

- **用时**：50～80 分钟。
- **讲解**：命令意图、修改前后值、稳定目标 ID 和失败。
- **核心练习与边界**：为材质参数编辑增加一条可撤销操作，先保持单步。
- **验收**：撤销准确恢复前值，目标已删除时明确失败而非访问悬空对象。

### H06：重做与有限历史

- **用时**：50～80 分钟。
- **讲解**：历史游标、新操作截断重做分支、容量上限。
- **核心练习与边界**：在 H05 基础上加入重做与有界历史，暂不合并复杂拖动命令。
- **验收**：修改／撤销／重做序列可重现，新修改后的分支行为可解释。

### H07：固定尺寸预览导出

- **用时**：60～90 分钟。
- **讲解**：离屏目标、读回、图片编码与输出文件生命周期。
- **核心练习与边界**：用现有离屏场景导出一张预览；编码依赖如需新增先评估确认。
- **验收**：尺寸／方向／颜色正确，失败不返回假文件；不批量导出视频。

### H08：编辑事务架构复盘

- **用时**：30～50 分钟。
- **讲解**：操作校验、应用、撤销与外部产物的不同可逆性。
- **核心练习与边界**：追踪一次编辑和预览导出，明确场景修改与文件写入边界。
- **验收**：操作历史不持有短命 UI 指针，导出失败不会破坏场景。

## 第三组：先用假服务练状态机

### H09：生成任务状态机

- **用时**：40～70 分钟。
- **讲解**：排队、运行、成功、失败、取消与终态不变量。
- **核心练习与边界**：写状态转换表和纯 CPU 转换函数，用固定事件序列验证。
- **验收**：非法跳转被拒绝，终态不会被晚到进度覆盖。

### H10：本地假服务与轮询

- **用时**：50～80 分钟。
- **讲解**：任务 ID、可重复响应、轮询间隔与 UI 不阻塞。
- **核心练习与边界**：用固定脚本模拟排队到成功，客户端消费已有任务快照。
- **验收**：相同事件可重放，等待中能操作场景，无需真实 API 或费用。

### H11：取消与晚到响应

- **用时**：45～75 分钟。
- **讲解**：本地取消意图、远端取消结果和版本判定。
- **核心练习与边界**：在假服务中模拟取消后成功响应，按契约处理过期结果。
- **验收**：取消不误显示新素材，能解释取消请求不等于远端一定停止。

### H12：任务状态架构复盘

- **用时**：30～50 分钟。
- **讲解**：网络事件、客户端状态、UI 展示与资源发布。
- **核心练习与边界**：检查状态机是否混入 HTTP／OpenGL，实现两个失败序列的复盘。
- **验收**：纯 CPU 状态可独立验证，线程与资源寿命沿用已有明确边界。

## 第四组：真实传输的最小基础

### H13：HTTP 客户端依赖与边界

- **用时**：30～60 分钟。
- **讲解**：连接／读取超时、TLS、错误分类和平台支持。
- **核心练习与边界**：评估一种库与平台 API 的替代方案，定义传输接口后等确认。
- **验收**：用途、许可证、构建成本明确；凭据不写进示例源码。

### H14：提交请求与响应解析

- **用时**：60～90 分钟。
- **讲解**：请求体校验、状态码、业务错误和任务标识。
- **核心练习与边界**：在已确认依赖下连接受控测试端点，提交最小请求并解析结果。
- **验收**：成功／坏请求／坏响应可区分，主线程不阻塞等待网络。

### H15：超时与轮询终止

- **用时**：50～80 分钟。
- **讲解**：单次请求超时、整体截止时间和终态停止条件。
- **核心练习与边界**：用受控端点制造延迟与不结束任务，实现有上限的等待策略。
- **验收**：超时可见且停止无效轮询，退出程序能收尾网络任务。

### H16：传输与业务职责复盘

- **用时**：30～50 分钟。
- **讲解**：HTTP 失败和任务失败的区别、请求寿命与回调捕获。
- **核心练习与边界**：画一个请求从发出到结束的所有权／线程图。
- **验收**：传输模块不修改场景，错误保留足够诊断信息但不泄露凭据。

## 第五组：可靠下载与缓存

### H17：重试、退避与幂等键

- **用时**：50～80 分钟。
- **讲解**：可重试条件、重复提交、幂等的服务端契约。
- **核心练习与边界**：模拟响应丢失后重试同一逻辑任务，限制次数与总时长。
- **验收**：未生成重复任务；不支持幂等时显式保留不确定状态而非盲目重发。

### H18：有界下载到临时文件

- **用时**：55～85 分钟。
- **讲解**：流式接收、大小限制、取消、临时产物和最终发布。
- **核心练习与边界**：下载一份受控素材到临时位置，成功后再形成可用产物。
- **验收**：中断和超限不留下假成功文件，UI 保持响应，目标路径可控。

### H19：内容校验与缓存命中

- **用时**：50～80 分钟。
- **讲解**：摘要、长度、格式验证、身份与内容版本。
- **核心练习与边界**：校验 H18 产物并复用已有缓存，分别制造损坏和重复下载。
- **验收**：损坏文件不进入资源系统，相同有效内容可复用，来源信息保留。

### H20：网络到资源发布复盘

- **用时**：30～50 分钟。
- **讲解**：下载完成、校验通过、导入成功与场景可见的不同状态。
- **核心练习与边界**：画完整产物状态链，检查临时文件和 GPU 资源各自的清理责任。
- **验收**：任何失败都能回到明确状态，不把 HTTP 成功等同于模型可显示。

## 第六组：Tool Calling 契约

### H21：工具请求与结果协议

- **用时**：40～70 分钟。
- **讲解**：工具名、调用 ID、参数、结构化结果和错误码。
- **核心练习与边界**：为已有材质编辑操作写请求／结果样例，包括一次失败。
- **验收**：不靠自然语言猜参数，结果能关联原请求并区分用户错误与内部错误。

### H22：参数 Schema 与校验

- **用时**：50～80 分钟。
- **讲解**：JSON Schema 的对象字段、类型、范围与版本。
- **核心练习与边界**：为 H21 工具接入最小校验；新校验依赖先评估确认。
- **验收**：缺字段、错类型、越界值在执行前被拒绝，未知字段策略明确。

### H23：本地工具分派

- **用时**：50～80 分钟。
- **讲解**：白名单分派、主线程操作队列和统一错误回传。
- **核心练习与边界**：让一条已校验调用进入现有可撤销材质命令。
- **验收**：参数改动可见且可撤销，非法请求不产生半次修改，不暴露任意命令执行。

### H24：工具与场景架构复盘

- **用时**：30～50 分钟。
- **讲解**：模型提出意图、客户端校验、应用命令和渲染响应。
- **核心练习与边界**：用成功／目标失效两条路径检查权限与寿命边界。
- **验收**：工具层复用现有业务操作，不另写一套直接改 GPU 状态的路径。

## 第七组：受控素材操作

### H25：工具操作范围与可预览结果

- **用时**：45～75 分钟。
- **讲解**：目标范围、允许路径、可撤销性与操作预览。
- **核心练习与边界**：为现有工具限定可修改对象，先生成可审阅的参数变化再应用。
- **验收**：越界目标被拒绝，预览与实际修改一致；不建设通用企业权限系统。

### H26：导入素材工具

- **用时**：50～80 分钟。
- **讲解**：受控产物引用、导入校验、稳定资源 ID 与重试结果。
- **核心练习与边界**：把已下载校验的产物交给现有导入流程，返回资源／实例标识。
- **验收**：失败不污染当前场景，重复调用行为明确，不允许任意路径读写。

### H27：生成预览工具

- **用时**：50～80 分钟。
- **讲解**：固定场景输入、相机参数、导出任务与结果引用。
- **核心练习与边界**：将 H07 导出封装成一个结构化工具，复用已有任务机制。
- **验收**：返回实际存在且可查看的预览，错误关联调用 ID，不把内存指针当结果。

### H28：工具链架构与检索需求复盘

- **用时**：30～55 分钟。
- **讲解**：工具组合、数据溯源、RAG 适用问题与额外成本。
- **核心练习与边界**：画导入／编辑／预览的组合路径，并判断是否存在真实知识检索需求。
- **验收**：默认先用现有素材信息；无明确需求不接 RAG，若需要则另立可验收小课。

## 第八组：真实服务与 v1.0

### H29：一种真实生成服务接入

- **用时**：60～90 分钟。
- **讲解**：当时服务协议、费用边界、认证、生成产物与工具调用的区别。
- **核心练习与边界**：在具体服务及使用范围获确认后，替换假服务适配器完成一次小素材生成。
- **验收**：得到可校验真实产物，费用／请求结果有记录；没有接入时只标模拟链路通过。

### H30：端到端失败恢复演练

- **用时**：50～80 分钟。
- **讲解**：跨网络、导入、编辑和预览的失败归因与恢复。
- **核心练习与边界**：用已有工具完成一条生成到预览流程，再注入一次下载或导入失败。
- **验收**：成功产物可查看，失败保留可用场景且可恢复，日志可关联整个任务。

### H31：作品集与求职材料

- **用时**：50～80 分钟。
- **讲解**：技术贡献、支持范围、数据证据与项目年限的区别。
- **核心练习与边界**：整理现有架构、生命周期、性能、故障报告和视频，准备针对真实岗位的说明。
- **验收**：每项能力有证据链接，不把课程时间描述成商业经验或专家资历。

### H32：v1.0 验收与两年复盘

- **用时**：60～90 分钟。
- **讲解**：素材创作闭环、跨平台结果、工程质量与真实协作机会。
- **核心练习与边界**：审阅整套现成证据，核对真实服务闭环和稳定版本，再调整进阶方向。
- **验收**：达到路线验收且遗留问题透明；投递／公开发布按具体授权执行。
