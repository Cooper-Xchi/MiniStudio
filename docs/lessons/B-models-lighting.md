# B 阶段：模型、光照与多遍渲染

[返回逐课索引](README.md) · 第 4～6 月／第 14～26 周

> 状态：全部为待执行教案，开课时依据实际进度和工具支持复核。

## 阶段前置与共同边界

A 阶段 v0.2 已验收；已掌握矩阵、相机、索引、纹理、深度和透明的受控实验。先选一份体积小、许可明确的 glTF 测试素材，支持范围从单个三角形 primitive 开始。

CPU MeshData 拥有顶点／索引数组，GPU 网格对象独占缓冲；材质先用值对象组合参数和资源引用。解码与格式解析不得调用 OpenGL，上传仍在 current context 所在线程。glTF 解析依赖先评估并经确认，暂不实现完整格式、自研解析器、IBL 或跨后端接口。

课内按顺序推进，后课以前课的验收成果为前置；每课只完成下列一个核心练习。若环境准备或实现超过 90 分钟，拆课并更新实际课号，不省略验收。所有实现课都须实际读改动并完成与风险相称的构建／运行检查；复盘课如改代码，也须补做行为回归。

## 第一组：法线与最小光照

### B01：CPU 网格数据与顶点布局

- **用时**：50～80 分钟。
- **讲解**：vector 的连续存储、size 与字节数、顶点布局契约。
- **核心练习与边界**：把立方体数据整理为最小 MeshData，并复用已有上传路径；不建资源缓存。
- **验收**：画面不变，能解释 data() 借用何时失效，非法索引能在上传前发现。

### B02：面法线与方向可视化

- **用时**：45～75 分钟。
- **讲解**：法线、叉积、单位向量以及位置与方向的区别。
- **核心练习与边界**：给立方体补逐面法线，用颜色显示方向；只验证几何数据。
- **验收**：六面方向可预测，零长度法线有明确处理，UV 仍正确。

### B03：一盏方向光的漫反射

- **用时**：50～80 分钟。
- **讲解**：点积、光线方向约定、漫反射与坐标空间一致性。
- **核心练习与边界**：在同一空间计算一个方向光的漫反射；先固定白色材质。
- **验收**：转动物体时亮面正确；能解释负点积如何处理以及为什么要归一化。

### B04：网格与光照数据边界复盘

- **用时**：25～45 分钟。
- **讲解**：CPU 属性、GPU 布局、逐物体矩阵和逐帧灯光的更新频率。
- **核心练习与边界**：画一页数据流，检查 Renderer 是否开始承担几何生成职责；不新增效果。
- **验收**：每项数据都有所有者，能定位一个 stride 错误与一个空间混用错误。

## 第二组：变换与材质参数

### B05：非均匀缩放后的法线

- **用时**：45～75 分钟。
- **讲解**：法线矩阵、逆转置的目的及奇异变换边界。
- **核心练习与边界**：对比普通变换与法线矩阵，在斜面测试物体上施加非均匀缩放。
- **验收**：光照结果符合表面方向，能解释为什么旋转实验不足以暴露问题。

### B06：最小高光模型

- **用时**：50～80 分钟。
- **讲解**：观察方向、反射／半程向量、指数与高光范围。
- **核心练习与边界**：给现有单灯场景加一种高光模型；不同时实现多种光照体系。
- **验收**：相机移动时高光变化合理，能分清物体颜色与高光参数。

### B07：Material 参数值对象

- **用时**：45～70 分钟。
- **讲解**：struct、默认值、const 借用和数据驱动参数。
- **核心练习与边界**：将颜色、粗略高光参数从绘制代码移入最小材质值对象，显示两种材质。
- **验收**：两个物体共享几何仍可不同外观，Material 不创建或销毁窗口。

### B08：材质与资源所有权复盘

- **用时**：25～45 分钟。
- **讲解**：组合、值对象与资源对象的差别，暂借引用的生命周期。
- **核心练习与边界**：记录 Mesh／Material／Texture 的边界和当前借用关系，检查销毁顺序。
- **验收**：能解释谁释放纹理，不能用无理由 shared_ptr 掩盖所有权。

## 第三组：受控 glTF 导入

### B09：glTF 结构与解析依赖评估

- **用时**：30～60 分钟。
- **讲解**：scene、node、mesh、primitive、buffer、accessor 的关系。
- **核心练习与边界**：手画一个最小文件的数据引用图；比较成熟解析库的用途、许可证与维护成本。
- **验收**：能定位位置和索引来源；形成依赖选择说明，获确认前不安装。

### B10：从 accessor 读取一个 primitive

- **用时**：60～90 分钟。
- **讲解**：偏移、stride、分量类型、数量及边界检查。
- **核心练习与边界**：在已确认依赖下把一个受支持 primitive 转成 MeshData；只做 CPU 路径。
- **验收**：已知顶点和索引数一致，截断缓冲被拒绝，错误指出对应字段。

### B11：显示第一个导入网格

- **用时**：50～80 分钟。
- **讲解**：导入数据与 GPU 格式适配，资源初始化失败回滚。
- **核心练习与边界**：将 B10 的网格接到已有上传与绘制接口；使用默认材质。
- **验收**：模型位置、索引和法线正确，失败时不留下半初始化 GPU 对象。

### B12：导入链路与受支持范围复盘

- **用时**：30～50 分钟。
- **讲解**：格式对象、项目数据和 GPU 数据的依赖隔离。
- **核心练习与边界**：记录已支持的 primitive／属性类型及明确拒绝项；追踪一次失败。
- **验收**：不把库类型扩散到 Renderer，缺属性或不支持拓扑有可读提示。

## 第四组：节点、纹理与失败路径

### B13：导入节点变换

- **用时**：50～80 分钟。
- **讲解**：glTF 节点的局部变换与父子组合，矩阵约定。
- **核心练习与边界**：在 CPU 导入阶段遍历一个小层级，生成只读绘制实例及世界矩阵。
- **验收**：同一网格的两个节点实例位置正确；不提前实现可编辑场景树。

### B14：基础色纹理与 UV

- **用时**：50～80 分钟。
- **讲解**：材质纹理引用、纹理坐标和图片方向约定。
- **核心练习与边界**：为受控模型接入一张基础色纹理；核对是否需要沿用现有图片翻转。
- **验收**：非对称素材方向正确，能解释 glTF 与当前解码约定怎样衔接。

### B15：导入错误结果与默认材质

- **用时**：45～75 分钟。
- **讲解**：optional 表示可缺省数据，variant 表示互斥结果；默认值与失败分类。
- **核心练习与边界**：区分缺可选材质与坏必需数据；前者回退，后者保留旧场景并报告。
- **验收**：两种故障各有可复现实验，不把损坏索引静默当成空模型。

### B16：模型版本 v0.3 复盘

- **用时**：40～70 分钟。
- **讲解**：支持范围、资源销毁、依赖版本与复现材料。
- **核心练习与边界**：汇总已稳定的导入场景和一份错误案例，检查多次加载／退出。
- **验收**：v0.3 可复现，库版本和素材许可有记录，未验证的平台独立注明。

## 第五组：颜色空间与离屏目标

### B17：线性颜色与 sRGB 边界

- **用时**：50～80 分钟。
- **讲解**：存储编码与光照计算空间、颜色纹理与数据纹理。
- **核心练习与边界**：用灰阶测试图统一一次解码／编码路径；记录每张纹理的语义。
- **验收**：能指出颜色在哪里转换，避免重复转换；数据纹理不按颜色解码。

### B18：最小离屏 Framebuffer

- **用时**：60～90 分钟。
- **讲解**：FBO、颜色／深度附件、完整性及尺寸所有权。
- **核心练习与边界**：封装一个固定尺寸离屏目标，先渲染现有场景；不加入后处理。
- **验收**：完整性检查成功，故障尺寸有错误信息，附件先于 Context 释放。

### B19：全屏呈现离屏颜色

- **用时**：50～80 分钟。
- **讲解**：两遍绘制、采样输入与输出目标、viewport 和状态交接。
- **核心练习与边界**：将 B18 颜色附件通过全屏三角形显示到窗口；仅做原样拷贝。
- **验收**：与直接绘制基本一致，resize 行为明确，未同时读写同一附件。

### B20：多遍渲染架构复盘

- **用时**：30～50 分钟。
- **讲解**：pass 顺序、附件所有权、窗口目标与离屏目标生命周期。
- **核心练习与边界**：绘制两遍数据依赖，检查失败和恢复默认目标的路径。
- **验收**：可解释黑屏源于哪一遍，不为两遍绘制引入通用 RenderGraph。

## 第六组：HDR 与最小 PBR

### B21：浮点颜色目标与 HDR 数值

- **用时**：45～75 分钟。
- **讲解**：颜色范围、浮点附件和显示范围的区别。
- **核心练习与边界**：将离屏颜色改为合适的浮点格式，输出大于 1 的受控亮度。
- **验收**：可通过读回或诊断证明高亮未在离屏阶段被截断，格式支持有检查。

### B22：曝光与 Tone Mapping

- **用时**：45～75 分钟。
- **讲解**：曝光缩放、映射到显示范围以及最终颜色编码。
- **核心练习与边界**：在现有全屏遍加入一种简单色调映射和曝光参数。
- **验收**：曝光改变高亮细节，能区分映射与 sRGB 编码，画面对照有记录。

### B23：单灯金属度／粗糙度着色

- **用时**：60～90 分钟。
- **讲解**：微表面模型的各项作用、金属度与粗糙度的语义。
- **核心练习与边界**：在给定函数接口和推导示例下补一个单灯 BRDF；先用常量参数。
- **验收**：用固定参数组合解释高光和漫反射变化；本课不做 IBL 或材质大全。

### B24：颜色与材质管线复盘

- **用时**：30～50 分钟。
- **讲解**：基础色、标量参数、HDR 目标和显示转换的完整路径。
- **核心练习与边界**：对一帧每个输入／输出标记空间、范围和归属。
- **验收**：能定位重复 gamma 与粗糙度误当颜色的错误，材质接口保持最小。

## 第七组：最小阴影

### B25：从光源观察深度

- **用时**：60～90 分钟。
- **讲解**：光空间、深度目标、光源投影与遮挡记录。
- **核心练习与边界**：为一个方向光渲染固定范围的深度图，并先可视化它。
- **验收**：深度图能辨认遮挡物，附件与 viewport 正确；不加级联阴影。

### B26：阴影深度比较

- **用时**：50～80 分钟。
- **讲解**：光空间坐标变换、比较深度与阴影范围边界。
- **核心练习与边界**：在接收面上比较光源深度，使用一次基础采样。
- **验收**：移动遮挡物时阴影跟随，光锥外行为明确，能解释两个深度来自哪里。

### B27：阴影偏移与伪影实验

- **用时**：45～75 分钟。
- **讲解**：自遮挡、精度、偏移导致的脱离及取舍。
- **核心练习与边界**：在同一场景逐项改变偏移，保存过小／合适／过大三组证据。
- **验收**：能区分 acne 与阴影脱离，参数有场景依据而非盲目调大。

### B28：阴影与多遍状态复盘

- **用时**：30～50 分钟。
- **讲解**：深度遍、主场景遍和呈现遍的状态与附件依赖。
- **核心练习与边界**：查清每遍清除、写入、viewport 和绑定顺序，注入一次错误定位。
- **验收**：三遍恢复正确，深度目标由明确对象拥有，无跨层全局状态。

## 第八组：整合与阶段验收

### B29：固定核阴影过滤

- **用时**：45～75 分钟。
- **讲解**：多次比较后平均、采样间距与质量／成本。
- **核心练习与边界**：在已有阴影上加入一个小固定核 PCF，对比单次采样。
- **验收**：边缘变化可复现，记录采样次数；不扩展软阴影算法研究。

### B30：金属度／粗糙度纹理

- **用时**：50～80 分钟。
- **讲解**：glTF 通道语义、数据纹理、常量与纹理因子的组合。
- **核心练习与边界**：给已有材质补一张受控参数纹理，保持单灯着色路径。
- **验收**：各区域参数可预测，通道映射有说明，缺图时回退常量。

### B31：v0.4 演示与复现材料

- **用时**：45～75 分钟。
- **讲解**：功能支持说明、素材来源、故障记录与作品表达。
- **核心练习与边界**：用现有模型录制 2～3 分钟演示，整理运行步骤和一份故障复盘。
- **验收**：另一环境可按说明尝试复现，未支持特性没有被宣传为已实现。

### B32：阶段验收与季度调整

- **用时**：45～75 分钟。
- **讲解**：从功能、原理、结构和实际投入评估下一阶段。
- **核心练习与边界**：回顾现成证据并做关键场景回归；列出需补课的导入／光照薄弱点。
- **验收**：v0.4 达到路线验收，资源生命周期清楚；只据证据调整 C 阶段计划。
